# NOVA UNIVERSE — WhatsApp-бот (подключение к аккаунту по коду сопряжения)

Бот работает как «связанное устройство» вашего аккаунта WhatsApp (как WhatsApp Web), без Meta Business и без QR.
Состав: **Node-шлюз на Baileys** (`gateway/`: сопряжение, приём и отправка сообщений) + **Python-ядро** (`wa_core.py`:
провайдеры, сессии, память, навыки, vision, формы ключей). Это неофициальный способ.

## Важно
- Неофициальные клиенты нарушают условия WhatsApp: возможна блокировка номера. Используйте отдельный номер или
  принимайте риск. Бот намеренно ведёт себя «по-человечески» (паузы, индикатор набора, очередь отправки).
- По умолчанию (`ALLOW_ALL=0`) бот отвечает **только вам в чате «Мне»** (Message yourself) и номерам из `ALLOWED_NUMBERS`.
  Группы игнорируются.

## Как это работает
1. Запускается контейнер, шлюз просит у WhatsApp код сопряжения для номера `WA_PHONE`.
2. Код отдаёт `/pair?key=PAIR_KEY` (ноутбук показывает его в Colab). На телефоне: WhatsApp → Настройки → Связанные устройства →
   Привязка устройства → «Привязать по номеру телефона» → введите код.
3. Сессия шифруется и бэкапится в приватный репозиторий `<repo>-backup`, поэтому после рестарта Render повторно вводить код не нужно.

## Использование
Напишите себе в чат «Мне» `/menu`. Меню приходят пронумерованным списком: ответьте цифрой (кнопок в обычных аккаунтах нет).
Команды: /menu /models /model /providers /key /addprovider /mode /status /vision /sessions /new /session /rename /history /export /clear
/memory /remember /forget /skills /addskill /delskill /settings /temp /system /help.
Фото, стикеры и текстовые файлы передаются модели; для картинок нужна vision-модель (👁 в /models).
Ключи провайдеров вводятся по одноразовой ссылке `/key`, а не в чате.

## Локальный запуск
    docker build -t nova-wa . && docker run --env-file .env -p 10000:10000 nova-wa

## Ограничения free-плана Render
- Сервис засыпает без входящих HTTP-запросов, поэтому нужны «будильники» (самопинг, GitHub Actions, пинг из Colab).
- Диск стирается при рестарте: БД и сессия WhatsApp восстанавливаются из зашифрованных бэкапов (раз в 1–5 минут).
- При деплое два экземпляра могут ненадолго держать одну сессию: WhatsApp разорвёт старый (бот подождёт минуту и переподключится).
  Не редеплойте без нужды.

## Персона и модель по умолчанию
- `persona.txt` — системный промпт NOVA-Spark-5, добавляется ко **всем** моделям (режимы /mode дополняют его, а не заменяют). Меняйте файл и перезапускайте сервис.
- Модель по умолчанию **NOVA-Spark-5**: пользователи видят только это имя, внутри используется OpenRouter Free Models Router (`openrouter/free`). Для неё любые сбои (лимит, сеть, нет ключа, пустой ответ) показываются как «⚠️ Лимит закончился. Попробуйте позже.»; настоящая причина пишется только в логи сервера. Нужен ключ OpenRouter (`DEFAULT_OPENROUTER_KEY`).
- Защита публичного номера: не более `RATE_LIMIT_PER_HOUR` (по умолчанию 40) сообщений в час на пользователя; владелец («Мне») без лимита.
